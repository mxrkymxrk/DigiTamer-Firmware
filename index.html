01 // INITIALIZE YOUR DIGITAMER

Flash the V-Pet

The installer runs directly in a supported Chromium-based browser. Connect the AIPI Lite with a data-capable USB cable and deploy the current firmware.

Connect your device
Plug the AIPI Lite into this computer over USB.
Enter bootloader mode if needed
Hold BOOT while connecting USB, wait about three seconds, then release.
Install DigiTamer
Select the ESP32-S3 serial device when your browser asks.
⚠ ALPHA FIRMWARE — recovery flashing may occasionally be required. A fresh install can erase saved device data depending on the install operation selected.
