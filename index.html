02 // 0.1.x → 0.2.x MIGRATION

ONE USB FLASH REQUIRED

Devices running 0.1.x cannot securely bootstrap 0.2.0 over Wi-Fi because the OTA certificate trust bundle changed. Install 0.2.0 from this page over USB once. After that migration, compatible future 0.2.x releases are intended to use DigiTamer's signed Wi-Fi updater.
