04 // 0.1.x → 0.2.x MIGRATION

ONE USB FLASH REQUIRED

Devices running 0.1.x cannot securely bootstrap 0.2.x over Wi-Fi because the OTA certificate trust bundle changed in 0.2.0. Install a current 0.2.x build from this page over USB once. After that migration, compatible later 0.2.x releases can use DigiTamer's signed Wi-Fi updater.
